# Compétences Spécifiques — Présentation Commerciale B2B

Ce fichier définit les compétences de rédaction **spécifiques aux présentations commerciales B2B**. Ces règles s'ajoutent aux principes universels de `presentation-excellence.md`.

**Usage** : Chargé quand le type de présentation = "commercial-b2b".

---

## Vue d'ensemble

Les présentations commerciales B2B ont des caractéristiques uniques :
- **Multi-stakeholder** : 6-10 personnes lisent le deck (dont beaucoup sans vous)
- **Buyer enablement** : Votre champion utilise vos slides pour vendre en interne
- **Decision committee** : Les executives ne lisent que les titres
- **ROI-driven** : Chaque affirmation doit être justifiable financièrement

---

## Règle 1 : Action Titles MANDATORY

### Contexte B2B
En commercial B2B, les Action Titles ne sont **PAS optionnels** — c'est le **standard absolu**.

### Pourquoi critique en B2B ?
1. **Buying committee** (6-10 personnes) lit le deck SANS vous présent
2. **Champion** utilise vos slides pour convaincre en interne
3. **C-level** ne lit QUE les titres (pas le temps pour le reste)

### Test de validation B2B
*"Si quelqu'un lit UNIQUEMENT les titres de toutes les slides, comprend-il l'argumentaire complet ?"*
→ Si OUI, les Action Titles sont corrects.

### Exemples B2B

| Type de slide | Action Title B2B |
|---------------|------------------|
| Problème | "Manual processes cost $2.1M annually in lost productivity" |
| Solution | "Automation reduces processing time by 73%" |
| Preuve | "Acme Corp saved $1.2M in the first 6 months" |
| ROI | "Typical ROI of 340% within 12 months" |
| Next Steps | "Start pilot in 2 weeks, full deployment in 90 days" |

## Règle 2 : Quantify Everything

### Contexte B2B
En B2B, les décisions sont **financières**. Chaque affirmation doit être traduisible en impact business.

### Catégories à quantifier

| Catégorie | Ce qu'il faut chiffrer |
|-----------|------------------------|
| **Temps** | Heures/jours économisés, time-to-value |
| **Argent** | Coûts réduits, revenus générés, ROI |
| **Risque** | Erreurs éliminées, conformité assurée |
| **Ressources** | FTEs libérés, capacité augmentée |
| **Performance** | Métriques améliorées (conversion, retention, etc.) |

### Transformation systématique

| Avant (qualitatif) | Après (quantifié) |
|--------------------|-------------------|
| "Faster processing" | "4h → 15min processing time" |
| "Cost savings" | "Save $127K annually" |
| "Better accuracy" | "Reduce errors from 12% to <1%" |
| "Improved efficiency" | "Handle 3x more requests with same team" |
| "Quick implementation" | "Live in 4 weeks, ROI in 3 months" |

### Règle d'or
*"Si tu ne peux pas le chiffrer avec les données du prospect, demande les données. Ne devine JAMAIS."*

## Règle 3 : Buyer Enablement

### Contexte B2B
Vos slides doivent être **utilisables par votre champion** pour vendre en interne, SANS vous.

### Critères de validation

| Critère | Test |
|---------|------|
| **Standalone** | Chaque slide est compréhensible sans contexte oral |
| **Shareable** | Le champion peut envoyer une slide isolée par email |
| **Quotable** | Les titres peuvent être cités en réunion interne |
| **Defensible** | Chaque chiffre a une source ou un calcul traçable |

### Implications pratiques

1. **Pas de jargon vendor** — Utiliser leur vocabulaire, pas le vôtre
2. **Pas de "nous"** — Toujours "vous" ou "[Nom entreprise]"
3. **Pas de références implicites** — Chaque slide doit tenir seule
4. **Sources visibles** — Si chiffre externe, citer la source

### Exemple

❌ **MAUVAIS** (non-standalone) :
```
TITRE : Key Benefits

• Comme mentionné plus tôt...
• Notre technologie propriétaire...
• Les résultats que nous avons vus...
```

✅ **BON** (standalone, shareable) :
```
TITRE : [Company] saves $340K annually with automation

• Process 500 requests/day → 1,500 requests/day (same team)
• Reduce errors from 8% to <0.5%
• Free up 4 FTEs for strategic work

Source: Based on [Company] baseline metrics (Q3 2024)
```

## Règle 4 : Tension/Résolution (Gap Dramatization)

### Contexte B2B
Le commercial B2B = vendre le **changement d'état**. Plus le gap est dramatique, plus l'urgence est perçue.

### Structure obligatoire

```
BEFORE (état actuel)     →     AFTER (état futur)
    Douleur                      Bénéfice
    Coût                         Économie
    Risque                       Sécurité
```

### Techniques de dramatisation

| Technique | Application |
|-----------|-------------|
| **Chiffrage du coût** | "Your current process costs $2.1M/year" |
| **Projection temporelle** | "In 12 months without action: $2.5M lost" |
| **Comparaison concurrence** | "Competitors have already adopted this" |
| **Deadline pressure** | "Audit in 6 months — are you ready?" |

### Exemples de slides Before/After

**Format 1 : Side-by-side**
```
┌──────────────────────┬──────────────────────┐
│       TODAY          │      WITH [PRODUCT]  │
├──────────────────────┼──────────────────────┤
│ 4 hours per request  │ 15 minutes           │
│ 12% error rate       │ <1% error rate       │
│ 8 FTEs dedicated     │ 2 FTEs (6 freed up)  │
│ $2.1M annual cost    │ $890K annual cost    │
└──────────────────────┴──────────────────────┘
```

**Format 2 : Gap visualization**
```
Current State ────[THE GAP: $1.2M/year]────→ Future State
   $2.1M cost                                  $890K cost
   12% errors                                  <1% errors
```

## Règle 5 : Objection Preemption

### Contexte B2B
Les objections VONT arriver. Mieux vaut les adresser proactivement dans le deck que de subir en Q&A.

### Objections B2B courantes à anticiper

| Objection | Où l'adresser dans le deck |
|-----------|----------------------------|
| "Trop cher" | ROI slide (payback period visible) |
| "Trop complexe" | Implementation slide (timeline simple) |
| "Risqué" | Social proof slide (cas clients similaires) |
| "Pas prioritaire" | Cost of inaction slide (urgence) |
| "Pas compatible" | Integration slide (leur stack) |

### Formulation proactive

❌ **Réactif** (en Q&A) : "Oui, c'est une bonne question sur le coût..."

✅ **Proactif** (dans le deck) :
```
TITRE : ROI of 340% with 4-month payback

Investment: $150K
Annual savings: $510K
Payback: 4 months
3-year ROI: 340%

"Our CFO approved in one meeting" — CFO, Similar Company
```

## Règle 6 : Personalization Depth

### Contexte B2B
La personnalisation en B2B n'est pas optionnelle — c'est ce qui différencie un pitch générique d'un pitch gagnant.

### Niveaux de personnalisation

| Niveau | Éléments personnalisés | Impact |
|--------|------------------------|--------|
| **Basic** | Logo prospect sur cover | Minimal |
| **Medium** | Leur industrie, leurs métriques baseline | Modéré |
| **Advanced** | Leurs données réelles, leurs workflows, leurs mots | Maximal |

### Éléments à personnaliser OBLIGATOIREMENT

1. **Nom entreprise** — Partout, jamais "votre entreprise"
2. **Industrie** — Exemples et cas clients du même secteur
3. **Métriques** — LEURS chiffres, pas des benchmarks
4. **Pain points** — LEURS mots exacts (discovery call)
5. **Stakeholders** — Mentionner les personnes par nom si pertinent
6. **Timeline** — LEUR deadline, LEUR événement déclencheur

### Exemple de personnalisation avancée

❌ **Générique** :
```
TITRE : Reduce operational costs

• Companies typically save 30-40%
• Implementation in 4-8 weeks
• ROI within 6-12 months
```

✅ **Personnalisé** :
```
TITRE : [Company] reduces operational costs by $340K/year

• Your current cost: $890K → Target: $550K (38% reduction)
• Go-live before Q4 audit (Oct 15)
• ROI by end of Q1 2025 (aligned with your FY planning)

Based on your baseline metrics shared on [date]
```

## Checklist B2B avant génération

Avant de générer un contenu commercial B2B, vérifier :

- [ ] Tous les titres sont des Action Titles (takeaway visible)
- [ ] Tous les bénéfices sont quantifiés (pas de "significativement")
- [ ] Chaque slide est standalone (compréhensible sans présentation orale)
- [ ] Le gap Before/After est dramatisé (coût de l'inaction visible)
- [ ] Les objections principales sont adressées proactivement
- [ ] La personnalisation utilise LEURS données (pas des benchmarks)
- [ ] Le nom de l'entreprise prospect apparaît (pas "votre entreprise")
